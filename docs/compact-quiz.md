# 整篇下拉答题（1.0.8）

做题界面仅显示题号与选项，不再将听力问题的书面题干显示在页面中。导入材料内的题干字段继续保留，材料编号、标准答案和音频关联不变。

同篇所有题目纵向排列在同一个页面，进入时展开当前题目，其余题目折叠。点击题目行下拉展开四个选项，同一时间只展开一题；选中后收起该题，并在行内显示完整的选项字母与文字。选择不会自动跳到下一题，其他题目始终留在同一页。较长内容可以在播放器上方滚动。

全部题目选好后，“提交本篇”统一提交尚未提交的答案并评分，提交前不显示正误和解析。提交后各题以图标标记状态，展开可查看标准答案与解析；“查看结果”进入整篇成绩页。已有提交答案保持锁定，其他题目的草稿保存在本地，重新打开后可继续。没有标准答案的题目仍可记录作答，不计入正确率。

题目下拉的展开与收起保持原有节点，通过短促的高度过渡回应操作；减少动画设置下取消过渡。共享文章录音不因切换题目行而重载；有独立分题录音时，展开题目切换对应录音，精听切换继续使用既有时间线映射。

“今日完成”仍按完整文章计数，统一提交整篇后记一篇；重复查看、收起或展开题目不增加记录。完整重做一轮可再记一篇。听力分钟、最近练习、套卷选择、资料导入与旧记录迁移继续沿用 [1.0.7 的统计口径](papers-and-completion.md)。
