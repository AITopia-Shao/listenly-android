# 整套录音与进度标记（2.0）

每套材料只有一个完整录音。首页置顶显示套卷，进度条覆盖整套；下面保留篇章目录，点击篇章定位到它的开始时间，右侧箭头阅览正文。正文分句时间叠加篇章起点，精听、做题、展开选项和调速共用同一个音频节点与绝对进度，不切换分题录音。顺序播放、整套循环和随机播放以当前考试合集内的套卷为单位。

做题选齐一篇后统一提交，答案与完成记录先保存，再直接进入下一篇第一题并定位到对应标记；最后一篇提交后显示结果。预览合集、套卷和正文不替换首页所选套卷，显式选择或实际播放才更新。

资料库层级为“考试合集 → 套卷 → 篇章”。默认提供六级、雅思、托福合集，可在导入清单中定义其他合集；没有资料的合集不会伪造考试内容。

## 本地资料迁移

本地个人题库的52套／100篇／900题保留原编号、原文、译文、选项及标准答案，播放改用52份原始完整录音；保留开场说明和题间停顿，不把切片拼成原始试卷。99篇标记来自已审核来源或原本完整录音的真实全长，1篇（2017年12月第1套 lt-19）缺少可信篇章时间，保留正文和题目并禁用该篇定位；不会根据前后空隙猜测时间。

篇章标记不代表已有逐句字幕。旧题库只有已具真实分句坐标的句子可跳转；无时间原文可读，不伪造平均时间。材料目录生成在本地 `materials/整套/`，不进入公开仓库。旧目录保留作备份，新包不再携带被替代的篇章或分题切片。

旧答题、收藏、完成计数和学习时长沿用原存储键及材料ID。旧文章进度在首次升级时加上已核实篇章起点，迁移为整套绝对进度；历史导入的切片文件夹保留其文字和题目，补充相同ID的整套录音与标记后可升级播放。

今日完成仍按完整提交的篇数计算。今日听力只在篇章标记范围被真正完整听过后入账；拖动跳过、读题间隙及未定位章节不会制造完成分钟，跨午夜按实际日期记录。总学习时长保留实际听音与前台做题时间。

## 壁纸与高刷新率

个人包使用用户指定的 Ten Peaks Day / Night 原始PNG；公开包继续使用项目原创SVG。两张图片在应用切换前预解码。现代WebView使用整页渲染外观的合成渐变，避免壁纸透明度变化令每层毛玻璃逐帧重绘；快速反向复用同一动画，减少动画设置立即生效。旧WebView使用兼容CSS渐变。

安卓按当前屏幕分辨率支持的模式优先请求120Hz，并在API35及以上对WebView申请相应刷新率偏好。未提供120Hz的屏幕使用受支持的高刷模式，60Hz屏幕保持系统默认；不强制切换分辨率。主题更新不再重复配置窗口布局与安全区。

刷新率请求不等于实测帧率。桌面浏览器与60Hz模拟器无法证明GT7稳定120fps；真实呈现还由系统、WebView与省电策略决定。性能数据及最终安装包／源码校验记录在本地版本验收文件中，未实测部分明确保留。

实现依据：[Android高刷新率](https://developer.android.com/media/optimize/performance/frame-rate)、[同文档View Transitions](https://developer.chrome.com/docs/web-platform/view-transitions/same-document)。
