# 1.0.13 倍速与流畅度调整

首页与正文的倍速按钮直接按 `1 → 1.25 → 1.5 → 1.75 → 2 → 1` 循环，不再打开选择弹窗。旧记录中的 `0.75` 自动迁移为 `1`；五个有效倍速均可保存并在重新打开应用时恢复。

切换倍速只调整现有音频节点的 `playbackRate`，保留同一音频源、播放进度和暂停／播放状态。暂停时点按不会开始播放；播放中点按不会暂停、重新加载或跳转。首页与正文共用倍速，进入同一篇正文时继续使用现有播放节点。答案草稿、收藏与已有学习记录不因倍速迁移改变。

## 减少重复工作，保留透镜表现

1. 只有正文可见、处于精听模式且存在分句区域时才同步句子。隐藏原文、首页和资料库不会因音频时间更新反复扫描正文；切句只更新前后两行。
2. 观察器按受影响的控件或列表子树同步，跳过无关时钟文本和生成的光学节点。播放时间、按钮状态、个人页数字等内容未改变时不再重写 DOM。静态透镜先集中读取几何，再写入样式；运动使用缓存尺寸，只更新强调值真正改变的文字。实际换行仍由尺寸观察器跟随，旧 WebView 在运动收敛时复核布局，无闲置轮询。
3. 日夜、精听／做题、隐藏／原文／双语及导航标签使用固定 `400`、`600` 字重两层，按透镜接近度交叉透明度。缩放、颜色强调、非线性移动和轻微粘滞形变保留，但不再每帧改变水平文字的字形度量。常规层保留唯一真实文本，强调层通过空的 `aria-hidden` 包装与 CSS 生成文字，避免文本读取和可访问名称重复。正文分句的动态字重与换行贴合保留。
4. 日夜颜色和壁纸透明度交由浏览器执行约 `300ms` 渐变，替代逐帧向根元素写入约 70 个颜色／材质变量。快速反向承接当前可见状态；减少动态效果时直接应用最终外观。切换主题不更换或重载正在播放的音频。

## 限定场景的测量

以下数据来自独立 Edge 探针，说明重复工作或布局成本的变化，不是所有场景的帧率承诺。

| 探针范围 | 调整前 | 调整后 |
| --- | ---: | ---: |
| 300 行列表，透镜跨 10 行运动期间的字体等样式变量写入 | 30,035 次 | 199 次 |
| 同一 300 行页面，12 次无关时钟文本更新引起的计算样式读取 | 7,212 次 | 0 次 |
| 固定应用快照、393 × 873 视口、4 倍 CPU 限速、6 次日夜切换；仅比较水平双字重层 | 69 次 Layout，约 1.864 秒 | 9 次 Layout，约 0.011 秒 |

上述双字重隔离对比的总任务时间也有下降，但不能与不同宿主负载或不同候选版本的数字拼接比较。另一组 4 倍 CPU 整页主题压力跟踪未观察到总体耗时改善，因此减少脚本写入、样式更新或布局次数，不等同于已经证明所有页面、所有手机的 FPS 提升。

## 已完成的验证

- 源码测试 74 项、构建资产与打包契约检查 5 项通过。
- [倍速回归](../tests/speed-cycle.test.mjs) 7 组通过，覆盖旧 `0.75` 迁移、暂停与真实播放中的完整循环、音频节点与源不变、进度不跳转、首页／正文共享、重新加载恢复和键盘操作。
- [闲置检查](../tests/ui-idle.test.mjs) 4 个页面通过：首页、个人页、资料库、正文停稳后的各 1,700ms 观察窗口内，应用观察器回调、DOM 写入、全局查询和应用 RAF 均为零。
- 独立几何探针对比 `contain:none` 与 `contain:layout`，9 个导航／分段选择场景及窄屏重排的位置、尺寸差异均为零，定位父级不变。
- 双字重文字探针 6 项通过：文本与可访问名称只出现一次，两个字重保持固定，交叉透明度有中间值；主题快速反向、训练模式和原文显示切换的透镜最终中心均对齐。

以上验证范围不包含 realme GT7 的本轮真机复测。
