# 外观、首页播放与按日统计（1.0.5）

收藏按钮在空心与实心书签之间切换。按钮背景始终透明，取消收藏不会留下悬停矩形，也不再弹出收藏提示框。键盘操作仍有图案焦点提示，系统要求减少动画时不播放过渡。

按钮使用短促的按压反馈，模式选择滑块从当前可见位置收束到最新选择；内容切换只轻微淡入，保持正文位置和播放器高度。首页播放与主题切换保留原有页面节点，列表不会因播放某篇文章而重排，播放图标由实际媒体状态驱动。快速反向操作会取消旧视觉状态，动画不延迟作答或播放。

听力首页、资料库和“我的”使用日间／夜间切换，精听／做题只出现在正文页。日间界面采用黑白灰，夜间使用近黑底和暖橙色文字；选择保存在本地，重新打开继续沿用，安卓状态栏和导航栏图标同步切换。活跃日历在日间使用绿色阶，在夜间使用橙色阶。

从首页、资料库或“我的”进入文章，默认精听并隐藏原文；正文内切换文章继续保留本次模式与显示选择。原“默认精听文本”设置移除，以免与每次进入的固定默认值冲突。模式时间线对齐、独立题目切片及播放错误恢复保留。

首页主卡和列表的播放按钮可直接播放／暂停相应音频，不进入正文；点击标题进入正文。切换主题不会中断首页音频。首页“全部”入口移除，资料库从底部导航进入。

## 统计口径

- 今日听力：设备本地当天累计的听音频秒数，换算为整数分钟。
- 今日完成：当天实际提交的题次。重新练习后再提交计入新题次；同一次提交的重复点击不重复计数。
- 总学习时长：历史听力时间加上前台做题且未听音频的时间，单位小时，显示一位小数。音频和做题重叠时间不重复累计，离开正文、隐藏页面或查看成绩不继续累计做题时间。
- 活跃日历：完整过去一年，以周日开始排列。每日题次的颜色阈值为 0、1–3、4–9、10–19、20 及以上；题次越多颜色越深。小屏只在日历内部横向滚动，默认展示最近的日期。

保留既有答案、收藏、学习秒数与导入材料。旧答案有提交时间时迁移到对应本地日期，只迁移一次；旧版已经被重做覆盖的历史提交次数、未记录的做题时长无法补回，不生成推测数据。旧版部分 WebView 的日期格式会规范为 `YYYY-MM-DD`，跨午夜听力和做题区间按实际本地日期拆分。
