# 1.0.11 统一透镜组件

导航保留可中断的物理透镜运动，底座改为半透明。外观、训练模式和正文显示方式使用相同的折射、形变与弹簧模型。播放器左右的倍速与播放方式共用尺寸和材质，首页与正文使用同一个播放器。

播放方式在顺序、单篇循环、随机之间切换，范围是当前套卷中有音频的文章。自然播完先结算完整收听，再续播；做题模式保留当前题目。按住进度条时延后续播，松开后只有仍在结尾才切篇，避免中断拖动。跳到结尾或跳过中段不会计为完整收听。

进度条保留原生范围输入与键盘操作，以独立玻璃轨道和灰色半透明手柄呈现。手柄按压放大，按钮按压缩小，释放后弹回；视觉缩放不缩小触控范围。拖动取消、失焦和多指释放会清理按压状态。减少动态效果时直接落点，不保留动画尾部。

日夜主题的背景、文字、边缘和高光由同一个 460 毫秒时钟插值。快速反向从当前可见颜色继续。菜单与导入弹窗有可中断的弹簧进出；关闭立即释放交互并恢复焦点，退场中的旧菜单撤去编号，快速重开不会产生重复的可访问性目标。

首页保留整套文章的顺序和节点，当前播放文章与资料库所选套卷采用同一透镜材质。正文标题不再承担选篇入口。设置中的重复倍速、导入弹窗中的格式编号说明已经移除。

实现参考 [Apple 材质规范](https://developer.apple.com/design/human-interface-guidelines/materials) 和 [Adopting Liquid Glass](https://developer.apple.com/documentation/technologyoverviews/adopting-liquid-glass)。Android WebView 使用本项目的 Canvas 位移图与 SVG 折射，未使用或宣称提供 Apple 原生控件。不支持背景滤镜的旧 WebView 保留透明层次、触控和弹簧行为；减少透明度或强制颜色时提供实色回退。

回归脚本：`npm test`、`npm run test:glass`、`npm run test:playback`，以及现有播放、主题、首页、布局与原生 Android 检查。`tests/replay-isolation.mjs` 仅在旧的播完重播回归中隔离自动队列，新的播放方式测试另用真实、未经隔离的自然 `ended` 验证。所有公开测试音频均为原创示例，六级资料不进入公共仓库或云端产物。
