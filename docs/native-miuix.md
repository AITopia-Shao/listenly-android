## 日夜开关

2.0.1 的整页截图渐隐也盖住了左上角开关。开关在下层移动时，上层截图仍显示旧位置，容易形成停顿后跳到终点的观感。

原生界面不截图覆盖控件。点击后开关立即更新本地目标，同一个 Animatable 从当前位置与速度继续运动；日夜壁纸以独立的图层透明度过渡。主题切换不会重建 ComposeView、Scaffold 或音频节点。进度消息以 250 毫秒为上限节流，未改变的目录与业务状态不重复发送；拖动时使用本地预览，松开后提交最终位置。

120Hz 是向系统提出的刷新率偏好。模拟器中的原生动画轨迹及 gfxinfo 只用于定位卡顿，不能据此声称 realme GT7 已稳定达到 120fps。

## Android 兼容与材料

最低 Android 8（API 26）。Miuix 模糊／运行时折射隔离在 API 33 专用实现内；Android 8–12 使用同一套原生交互、字体与动画，玻璃底材采用透明渐变兼容路径。清单只为隔离的 blur 模块覆盖依赖最低 API，不改变应用自身的最低版本。

应用编号、旧 localStorage / IndexedDB、私有导入目录与签名继续沿用。套卷录音不切片；篇章和分句仍以整套录音的真实进度标记跳转。个人轻量包保留七篇已校验的分句标记。

公开仓库、云端测试和公开演示包只使用原创材料及背景。个人六级材料和 Basic Apple Guy 壁纸继续留在本地构建中。Miuix、AndroidX、Kotlin 的许可说明见 [第三方声明](../THIRD_PARTY_NOTICES.md) 与 [Apache-2.0 全文](../LICENSES/Apache-2.0.txt)。

## 验证记录

原生桥使用真实兼容脚本、实际解码音频和原目录格式做回归，包括旧记录恢复、预览不提升首页、整套时间轴、分句、五档倍速、持久正误反馈、自动下一篇、完整导入与导出、闲置消息节流和拖动结束保护。

`tools/android-native-smoke.mjs` 安装实际 APK，以 Android 无障碍树定位并通过 ADB 点按原生控件。CDP 仅观察保留的音频引擎；不把网页 DOM 点击算作原生触控验证。测试不清除应用数据、不重置模拟器。运行结果、APK 散列、截图、轨迹和崩溃日志分别保存在 `.build/runtime-results/<label>/`。

最终 APK 和跨 API 云端结果完成后记录在发布说明中；本文件不将尚未运行的检查列为通过。
