# 2.0.0 验证范围

本版将每套材料的播放单位改为完整录音，篇章和分句仅标记时间位置。资料库采用考试合集、套卷、篇章三级目录；预览保留首页选择，选择或实际播放才更新。提交本篇后进入下一篇，末篇显示成绩。新导入标准见[材料格式](import-format.md)，升级边界见[整套时间轴](paper-timeline.md)。

最终应用源码为 `b986fc70972b180a72c6669929f70da8573e8f7e`，Android版本 `2.0.0 / 15`，最低Android 8.0。下表只列实际完成的验证；桌面与模拟器不能替代realme GT7真机复测。

所有最终包复用原签名，正常覆盖安装保留学习数据。最终轻量包、完整版和公开包的前端SHA-256均为 `75d6eb93f6753900d41d3b6a038dd55969924eba4aff463b331d620b2b338cb8`，样式为 `347b529feddc792870acb0fc5596416d324a8177e9e3a9b9ece9318b28ae5243`。

本地Windows样式包含522个CRLF，云端Linux的四份APK样式与Git原始LF文件逐字节相同，SHA-256为 `8adde8bcf47ce25c812ae29c68a169faed837b61c5bcb5628dd1010d4a04a944`。本地文件只将CRLF替换为LF后与该Git内容完全相同；审计分别保留实际哈希，不把两种原始字节描述为相同，也不允许其它内容差异。

公开包仅含一份完整原创英语录音、对应两篇原创练习、字体许可和项目原创SVG背景。个人照片、真题录音、原文及私有报告不进入公开Release。公开APK SHA-256：`a80fd0da98b7709078d77ebb3014d48abec24c13064b5c4881dfaffbbb62afb6`。

个人材料迁移保留52套、100篇、900题的ID、原文、译文、选项和答案，并逐字节核对52份原始完整录音与导出文件夹。99篇有核实标记；一篇缺少可信起点，保留阅读和做题并禁用该篇跳转。篇章标记不表示全部旧文章已有逐句时间戳，未补齐的字幕不会伪造分句定位。

[12轮性能对照](suite-2-performance.md)完整保留正常CPU与4倍限速的中位数、额外布局／脚本成本和测量条件。安卓优先请求支持的120Hz，**尚未实测GT7稳定120fps**。

早期失败继续保留在本地验收记录中：主题减少动画测试的媒体查询事件时序、测试音频的Range协议、窄屏调整后的透镜测量时机，以及短录音结束后仍引用旧按钮的原生测试断言。修正只改变对应测试的协议或观测方式，保留真实点击、音频结束、学习计数及越界检查。
