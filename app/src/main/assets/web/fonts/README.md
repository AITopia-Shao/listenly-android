# Inter 4.1

Unmodified web fonts from the official Inter 4.1 release:
https://github.com/rsms/inter/releases/tag/v4.1
https://github.com/rsms/inter/releases/download/v4.1/Inter-4.1.zip

Copyright (c) 2016 The Inter Project Authors (https://github.com/rsms/inter)
License: SIL Open Font License 1.1; see OFL.txt.

InterVariable.woff2 is used when variable fonts are supported. The original
Regular, Medium and SemiBold web files supply 400, 500 and 600 weights on
older WebViews. All fonts load from the APK without a network request.
Chinese text uses the device's system Chinese font. Apple system fonts and
SF Symbols are not bundled.
